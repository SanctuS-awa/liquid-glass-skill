# 先校准位移，再验三层折射

本节是量具和失效诊断，不是第四种折射。实现仍遵守 L1–L3 的规定；没有测位移的普通磨砂不能跳过本节宣称六层达标。用同一背景帧、相同裁剪和颜色设置，保存单独的折射输出。先关闭 L4–L6 和前景，别让模糊盖住断尾。

## 三帧校准：把中性错误和映射错误拆开

把有坐标标记的 X/Y 网格放在玻璃后面，网格细线在直边、圆角、中央都要有。HTML/SVG 路径可以用[随包诊断页](../assets/fixtures/displacement-calibration.html)校准浏览器；该页只验证测试方法，不能替代对成品使用同一流程。

| 测试 | 状态 | 判读 |
| --- | --- | --- |
| Z | 位移为零，保留真实位移图与相同滤镜/裁剪 | 确定无位移基线。弱色差不是坐标变化；用交点或标记质心核对。 |
| N | 非零位移增益，改用不透明中性位移图，保持真实映射参数 | 与 Z 比较，网格不应有可辨平移。若大片同向漂移，先查通道值域、传输函数、色彩空间、量化或透明预乘。 |
| R | 同 N 的增益，换回真实图 | 规定的中央无作用区内不应平移，近沿探针必须可辨位移。如果 N 对而 R 中央错，先查实际位移图尺寸、宽高比、局部原点和重算时机，不要先降折射强度。 |

不强制中央整块绝对零位移：只检验该轮廓与当前规模下被声明为折射支持区之外的区域。若组件很小，中央保护区无法容纳可辨探针，换同材质的大几何完成校准，并注明。未宣称零位移的几何不能拿来躲避对坐标基线和实际作用区的检查。

SVG 的中性样本是在**滤镜实际工作颜色空间**里的 0.5，不是发出数值 128 就保证中性。若把 sRGB 8 位 128 解码成线性光后直接做位移，值约是 0.216，近似偏移为 `−0.284 × scale`；此估算是诊断，不声称每个浏览器都会如此，先看 N。显式声明颜色空间并配套编码。8 位 128/255 也不正好是 0.5；若误差受量化支配，在验收前登记容差和推导，不允许事后用大容差掩盖错位。看 [W3C：feDisplacementMap](https://www.w3.org/TR/filter-effects-1/#feDisplacementMapElement)。

核对位移图写入和读取区域的实际数值以及 CSS px/设备像素的换算。如果位移图和面板尺寸不同，需明确预期缩放、对齐和宽高比，不能依赖未验证的百分比、默认居中保持比例或偶然正确的固定屏幕尺寸。至少测两种不等比面板尺寸，再在 1×/2× 重做。在 WebGL、Canvas 或原生上用等价的零位移坐标场测试；记录真实渲染路径，不拿另一种后端补票。

## L3：连续不是「有差值」

同一材质做正圆、胶囊、长圆角面板，选能跨过一处曲率转接或闭合参数接缝的同源细带，单独验 B2/B3。沿真实轮廓等弧长取样，步距先登记，至少覆盖到正常观看比例可追踪的终点。每个截面定位出现变化的连通条带，记录峰值和相对峰值宽度；用 B2 或逐个去源验证确为同一个来源。依次验证：

1. 从直接接触端到末端，不应缺一截后又亮回来。若仅增强差图能从断处续上，正常比例仍判失败。末端连续渐淡是正常的；不可跨可见空隙计行程。
2. 尾段至少两个可辨位置取局部正交截面，后段真实支持宽度或相对峰值宽度小于前段，不能只变暗。不要用单一绝对亮度阈值量宽。
3. 轻移来源，使同一尾巴跨过不同子像素相位并过接缝连续复测。若只在某个像素相位变回点断，检查边缘表示、重采样和抗锯齿；不能用 L4 模糊或 L5 白边补。
4. 两条尾巴邻接时，分别关闭一个源，再重复轻移。另一条应保持自己的走向来源。该对照是诊断，不能代替双源正常帧。

高分辨率位移图、按局部弧长适配采样密度、保持连续法线或在最终设备像素抗锯齿都是修法候选，不是强制算法。提交原尺寸无标注帧和定位图；差图可以辅助定位，不能单独证明视觉通过。
