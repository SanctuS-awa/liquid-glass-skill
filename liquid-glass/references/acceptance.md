# 验收协议：同源、逐层、可重做

**规范定义成像，验收定义证据。** 本协议不要求某个着色器、核函数、数值或模型。它要求相同输入下能看到规定的现象，且反例不会误触发。视觉结果与量测互相校验；没有证据标「未测」，不能按「看起来差不多」通过。

## 1. 锁定条件

1. 记录平台、实际渲染路径、视口、比例、轮廓、位置、背景、默认调参值、颜色空间和截图方式。关掉会改变底图的动画和自动曝光。做缩放或移动测试时只改变这一项，并锁定其余状态。
2. 用一套自绘测试底图（可直接用[随包素材](../assets/fixtures/README.md)）和一套不特调的实景/产品底图。测试三类轮廓：小胶囊、带直边的大圆角矩形、正圆；补测高窄矩形或说明该产品为什么用不到。保留带标注定位图和无标注原图，不能只给拼图、差分或强裁切。
3. 同帧导出 B0 原背景、B1、B2、B3、B4a（B3 + 普通模糊）、B4b（再加亮部扩散）、B5（加常规表面高光，关闭接触延色）、B6（加接触延色）、最终成品。B4a/B4b 做材质隔离时关闭额外调色或压暗，成品则保持真实默认值。B0–B6 是调试出口，不要求产品界面加开关。

## 2. 必须过的门槛

| 项目 | 必交证据 | 不能判通过的情况 |
| --- | --- | --- |
| L1 法向拉伸 | B0/B1 同一对标记在直边与圆角的法向间距增大；扫过直弧交点或闭合参数接缝，同一斜纹可连续追踪。 | 法向次序反转、标记重影、直边把标记拽向角。 |
| L2 正面展开 | B1/B2 同一对标记沿边间距增大、同时离边更近；另在正圆隔离出近沿的独立贡献。 | 一项代替两项、在直弧接点跳变、圆周出现虚构的端点。 |
| L3 细尾 | B2/B3 两个可区分来源，分别移除或轻移其一；至少一个尾巴跨分区中线；沿尾在两个位置测与轮廓正交的实际宽度。 | 只变透明度没变细、到中线硬切、藏接缝、两色混成跟不回来源的长带。 |
| L4 普通模糊 | B3/B4a，在中央、直边内侧和圆角内侧各标一块非高亮细纹。默认分辨率三处都可见变软；在实际组件上做无标签即时切换/盲摆对照，原可读背景小字变难辨但大色块仍可读，前景仍利落。锁定曝光，仅改宽模糊混合量，取低/默认/高三档作同帧对照。 | 只亮处有变化、近边整圈还锐利、只压暗或铺灰、只有放大/像素差下才看出来。 |
| L4 亮部扩散 | B4a/B4b，用同底色、同尺寸的孤立亮暗双探针测可见距离（下节）；原大小能指出亮源外连续软晕且较亮者更远，远离两者的近黑区域不自起亮晕；实景至少复核一处亮源。再用双触点验各自光晕仍围绕 B3 尾迹。 | 亮线只是变亮没变远、靠硬阈值出现断环、暗区铺色、核心搬家或尾迹被替换。 |
| L4 尺寸与内容响应 | 同轮廓换底先比背景色/普通模糊/光晕三者；同底图从小胶囊到大展开，在共同覆盖区域取五帧，另导出两个静态端点。至少一次横向移动玻璃穿过细纹与亮斑。 | 用不同底图比较大小；用透明度或压暗冒充强度；出现可见档位闪跳、滞留的旧模糊、前景跟着糊。 |
| L4/全开透射双门槛 | 同帧 B0/B3/B4a/B4b/B5/B6，正常尺寸且使用[模糊度双门槛](04-clarity-gate.md)。B4a 细纹比 0.40–0.85，主结构 ≥0.75；B6 主结构 ≥0.60，实景折射可追。 | 默认纹理没软化、糊成磨砂、L4 通过后被面内高光涂掉、仅放大才看出。 |
| L5 常规高光 | B4b/B5：中性底上用正圆、胶囊、长直边圆角面板，观亮核与向内柔肩、对角强弱、直段和圆弧的连续变化；分别量峰值与按各自峰值归一的法向宽度。纹理底复核不是背景线；高光随形变另验。 | 等宽只变白/变淡，只有角亮而长边两端一样，弱段压黑或硬断，靠 L6 遮瑕，动时双边或脱节。 |
| L5 常规冷暖 | L6 全关，冻结形状/曝光/配置。暖冷换位的两张底图各做 B4b/B5，再用独立高光颜色或还原出的贡献确认高光本身换色。再查中性底。 | 仅底图换色而高光仍白；高光逐像素追背景纹理；固定角落彩边；非要开 L6 才显色。 |
| L6 接触延色 | B5/B6 验扩散前真实来光；测同一直接接触段的两端各自向外延伸。普通暖/冷入射各一例，另做较暗或近等亮的有色入射，以及均匀底、原底已有同色、仅 L4 到达三种反例。关闭 L5 后再验无贡献。 | 色尾只出一端、仅靠强光才触发、只有光晕也染色、原高光被染成暗槽、高光外有变化。 |
| 同界面材质一致性 | 同屏放至少三件玻璃，先用同一张中性底看同规格组件，再换明暗或有纹理底，交换位置并核对共享参数；有主题切换时看整组同步。详见[同屏对照](material-consistency.md#同屏验收)。 | 同样的底图和轮廓仍出现一黑一白一透明；同规格圆角不一；仅一件切换主题或掉成另一种材质。 |
| 合成与降级 | 在暗底、明底与有细纹照片看原尺寸成品，明确指出一个前景文字/图标可读性观察。宣称实时或跨平台时，按目标后端记录移动/展开与背景不可用时的处理。 | 用离屏效果证明未实测的真实桌面、用 Canvas 近似路径证明 WebGL2，或把降级磨砂算作六层通过。 |

## 3. 量测不替代肉眼

- **L4 普通模糊：** 在 B3/B4a 的同一纹理区域记录梯度或局部对比，或记录同一条边的 10%–90% 明暗过渡宽度。保持取样区域和颜色空间相同。均匀中性底（远离其他光源）是曝光/补黑的对照；不要把梯度下降百分比当跨场景目标。
- **L4 亮晕距离：** 先在 B3 标两条光源各自的边界。沿未受剪影截断的同向剖面，看 B4b 比 B4a 增加的亮度；用同一个预先登记的阈值和最短连续长度找到两条探针各自的最远连续可见点，记录到各自 B3 边界的距离。阈值应高过近黑对照的扰动，最好再用一个略高的阈值复核排序。不要分别按亮核峰值归一，不量最大像素差来代替距离。记录单位（如 CSS px）和观看比例；末梢如果正常比例不可辨，应标未通过。
- **L5 法向宽度：** 对同帧线性亮度差 B5−B4b，在亮段、弱段和接点量峰值与各自相对峰值下的连续宽度；低信噪时须高精度贡献或标未测。用等宽只降增益的负例核对量具。
- **L3/L6 沿弧：** 用实际轮廓弧长，不用直线欧氏距离；登记直接接触端点、可见末点和局部剪切/遮挡。L3 同时量细带宽度；L6 同时查高光覆盖之外是否逐像素相同。阈值是本次量具，不是材质参数。
- **时间连续性：** 保留整段原速视频或用带时间戳的连续帧核实；五个状态帧用于定位，不足以证明整段没有闪跳。不用过渡遮住静态缺陷。

## 4. 跨模型盲测与报告

- 第一轮只给候选模型 **这份 Skill、固定素材和同一个中性任务**。不交给它 Astra 的代码、截图、参数或修法。不许为某张探针图写专用映射。先冻结产物再跑同一套验收；评审时再看苹果参考与非测试实景。
- 盲测任务可用：「用附带 Skill 做一套默认可用的六层液态玻璃，支持胶囊、圆角矩形和圆。交付可复跑示例及 Skill 要求的逐层证据。」不要为了让弱实现过关改阈值、换底图或调低对应层。
- 按「实现/模型｜后端｜层/子项｜通过/失败/未测｜证据及量测单位｜首次异常的层｜回归」记录。先查是否违反现有规范；只有多份独立实现反复在同一条出现合理歧义，才改规范。最后至少有一份不依赖 Astra 的独立产物通过同一矩阵，才可说本 Skill 已通过一次跨模型复现；否则只能说已写入跨模型验收。没有实景端点或未测平台时不要写「完整通过」。

既有《余照》隔离图可证明普通模糊的三处软化，以及高光之外的部分反例；旧记录中的亮暗峰值差不能替代距离量测，独立直边探针的双端 L6 也不能证明实景弧边全部归因。这些限制不要在复用证据时省略。

### 评审方反例：检查验收能不能拒绝假通过

- **L3 只淡不细：** 用同宽尾迹只减透明度的对照。单一亮度阈值会把淡尾误测成变窄；对每个截面按当地峰值做相对宽度量测，或核对实际输出支持宽度。只淡出的对照必须被拒绝。这条是 L3 尾迹规则；L5 的独立带宽要求按以下反例。
- **L5 只暗不窄：** 用等宽、同形的法向光带，只按沿边位置降低增益；它在绝对阈值下看起来变细，按各自峰值归一后宽度相同，必须拒绝。第三层尾迹和第六层色尾不能替代此验收。
- **L4 只暗不糊：** 在同一张 L3 上用等均值、初始对比相近的中性粗细条纹，关闭光晕与调色。记录线性平均亮度、细纹相对粗纹的对比比值。纯线性压暗会让两者一起变弱，不能证明普通模糊；真的柔化会相对更明显地削弱细纹，并让边缘变宽。此负例和实景的肉眼验收都要过。
- **L6 只晕不接触：** 构造 L3 与高光无接触、只有 B4b 的光晕进入高光的帧。B5/B6 应相同，比较的是同一帧开关差，B5 自身仍可以带常规冷暖；再把光源移到使 L3 实际触边的位置做正例，防止用关掉 L6 蒙混。
- 冻结候选后由评审方另外换一张未提前给出的实景或变形底图重复关键失败项。显式修改粗细、颜色或位置之一，不改判据。公开素材跑通而未公开素材失败，不能宣称复现通过。
