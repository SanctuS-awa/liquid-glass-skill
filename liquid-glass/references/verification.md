# 校准与逐层反例

下文解释各层为什么要这样测；正式交付的固定输入、判定与报告格式以[验收协议](acceptance.md)为准。

1. 先明确本次变更的层、固定层和基础背景。用一个稀疏斜线背景，以及散布有两个可追踪标记的双色小块背景；再用横跨中央、直边和圆角内侧的普通纹理、同尺寸、不同亮度的一对孤立光源（同底色、相近折射条件）与远离两者的近黑对照验证第四层；用接触标记辨别第六层的触发条件，再在成品画面验其双端延色。不要为单一图案调出专用映射。
2. 用同源前后对照：原图 → L1 → L1+L2 → L1+L2+L3 → 加扩散 → 加高光 → 加延色。检查弧、直段、切点和中央；用同一张横跨直弧交界的斜向宽色带，在 L1 与 L1+L2 两档标出同一源特征及其间距，禁止换背景来消掉接缝；正圆也要隔离验证 L2 的独立近沿贡献；小胶囊、大展开、不同长宽比与圆形至少能解释为何适用。全开不能抵消各层，不能只出一张不同背景的合成图。
3. 量测的是有意义的量：第二层开关前后两标记的沿边间距和各自的离边法向距离、接缝两侧源坐标差与局部倍率、细带法向宽度随弧长收窄、双触点尾迹靠近和跨中线时的来源连续性、第四层只读已折射的底图且扩散围绕各自的成像位置，且必须同时验普通纹理软化和亮部扩散（见[第四层同帧验收](04-diffusion.md)）、延色在直接接触段两端分别超出且不出高光。测试可用遮罩/像素差确认隔离，不以代码通过或理论满足冒充视觉验收。
4. 默认值优先建立在局部短边、有效半径、近沿可用深度、弧段与亮光扩散尺度；先调支持深度，再调增益/行程，最后调混合。不要用一组像素或一个比例覆盖所有形状。参数注明单位、默认来源、预期失效形态与调整方法，不强制正式 UI。
5. 现场无法得到同源背景时注明，不用猜测来填。记录哪些是视觉参考，哪些从代码可证，哪些已在目标平台实测。报告仍有的折痕、尾迹较弱或性能取舍；关弱该层、改测试目标或用模糊填缝不算修好。


## 折射开工检查与回归闸门

- **看实际查询坐标，再看屏幕。** 以输出像素回查源图。在上沿量向内为正的深度：L1 近沿查源应偏向内，越入内位移收回；沿法线前后取至少两个探针，源点次序不折回，且同一对源标记在画面里的间距确实变大。例：输出深度 4 和 8 的源深度若是 0.8 和 6.1，源段比输出段更宽，这是压缩，不是拉伸。L2 上沿右半若要把像往右拉，输出点应回查更靠该边中间的源点；左半镜像，竖边换轴。不用着色器位移的正负代替这些可观察结果。
- **融合着色器可以，证据不能融合。** B0/B1/B2/B3 从发布入口所用的同一几何、同一干净底图及同一实际取样路径导出。融合映射须能输出只计算到每一层的相应结果，且证明后一层取的是前一层的像（或给出等价的坐标复合）；简单相加几个位移后只采一次原图并不能证明等价。B0–B3 全关 L4–L6、外投影和内暗边。替代渲染器必须独立验证或明确标记降级差异，不可借另一条路径的合格图。
- **L3 防止用薄带平移冒充细尾。** 窄带里的固定宽度切移（即使随深度衰减）本身不证明尾迹跨线、同源、逐步变窄。核对源像的沿弧次序和同一特征是否被重复采样；在中线、圆弧切点和圆周回绕处同时检查。用双色探针的各自移除反例标出尾迹起点、末端和至少两处原尺寸法向宽度，优先检出反序、重复和硬切，不用阴影或高光藏。
- **最后做全开回归。** 在静止的实际场景里用至少一根跨直边/圆角的高对比线和一条大色块边界验证折射仍容易从原尺寸画面追踪；对照同底同形的 B0、B3 和成品，不能靠裁切、放大或背景自己在动。改阴影/模糊/高光的任务，如果沿用折射，记录实际渲染路径与已验基线，并复跑这一成品回归；如果换实现或换渲染路径，重跑折射逐层验收。提交报告按 L1/L2/L3 和各渲染路径逐项标记通过、失败或未测。

## 交付前逐层反例

固定默认档、同一背景、轮廓、位置和输出比例，保存相关对照。下列检查用来区分「没实测」和「通过」，截图或记录需同时说明观察到的结果。调试标记可以加减，但不得暗中驱动被测几何。

- **L1，原图 → L1：** 两标记与一条斜线检查默认档是否有折回、双像或内外采样顺序反转，且相邻标记的法向间距须可见地增大。让斜线穿过圆形轮廓参数的接缝（若用角度，如回绕处）及圆角方框的直弧交界；小范围跨过这些位置时，不应突然读到远处背景，或在原图没有边界处出现新断线。参见[第一层默认档](01-normal-stretch.md#默认拉伸的折回界限)。
- **L2，L1 → L1–L2：** 对照同一片像，两点沿边间距变大且离边更近；不能把查源方向当成像方向。用普通斜纹穿过胶囊的半圆切点与侧面极点，逐段检查没有跳变；正圆不虚构端点或产生切向跳变。
- **L3，L1–L2 → L1–L3，关闭 L4–L6：** 横边、竖边和圆弧的起始分区均垂直于当地切线。用橘蓝双触点让尾迹相遇，至少一条真实跨中线；分别移除单个标记、再轻移保留标记，检验来源可追、不断、不跳、不铺混色带。场景另放不绑定标记的普通斜纹。若演示有独立光源手柄，隐藏标记并维持源背景逐像素相同时，移动不可见手柄不得让普通斜纹凭空改变。细尾必须随行程实际变窄，不是只淡出。标出直接接触段和尾端，在正常比例下确认有可追踪的额外长度；若与旧版对比，固定来源和厚度，确认沿轮廓有效行程确有适度增加。参见[第三层验收](03-rim-stretch.md)。
- **L4，L1–L3 → L1–L4，关闭 L5–L6：** 先在 L3 标出亮核和已有尾迹，再开 L4，沿亮核向邻近暗区查看由近及远逐渐变淡；正常比例下要在亮核外看见更远、连续变淡的光；同帧调校对照时单独检查亮核位置、强度与外侧可见距离，不能把亮度增加或理论范围变大当成扩散延长，也不能有微弱光贡献在暗区变成硬环或另起色带。另以「L3 → 仅普通模糊 → 加入亮部扩散」的同帧对照分开验收；不靠光晕就能在正常比例看见普通纹理软化，若任务明确加强 B4a，应与旧档同帧比较；若仅修 B4b 或阴影，B4a 应保持不变。普通纹理在中央、直边内侧及圆角内侧都要软化，亮源较暗源扩散更远，不能靠关弱 L4 通过。参见[第四层验收](04-diffusion.md)。
- **L4 与最终合成联检：** 冻结同帧，按[模糊度双门槛](04-clarity-gate.md)量 B4a 细纹和主结构、B6 主结构；再正常大小追一条背景边的折射走势。模糊过强与不透明高光反例须分别被拒绝；修改高光不等于普通模糊已过。
- **L5，L1–L4 → L1–L5，关闭 L6：** 先在中性平底看较宽较亮的对角区、较窄较弱的丝光、长直段和直弧交界，再量各代表剖面的峰值与相对峰值宽度。拒绝等宽只淡、硬断、双边或把背景亮纹算进高光。保持 L6 关闭，暖冷底图换位用 B4b/B5 和高光贡献验收 L5 本身的混色；真正接触色与双端延色另用 B5/B6 验；支持形变时高光必须随同一轮廓重算。见[第五层独立验收](05-highlight.md#单独验收-l5)。
- **L6，L1–L5 → L1–L6：** 单切 L6，核对同帧的 L3 成像、底图和原高光覆盖相同，零覆盖处逐像素相同，关闭 L5 后 L6 无贡献。按[真与假触发的对照](06-contact-color.md#真与假触发的对照)分别核实真实抵达、原底已有、仅 L4 扩散三种情况，检查能送色过来的邻段；替换入射色或仅更换底色，分别核实色相归属。按[同一接触段的双端验收](06-contact-color.md#同一接触段的双端验收)提交成品同帧开关原图，逐端记录直接接触端点、可归因的可见末点及两者间的沿边距离。选用暗于当地高光的入射光，对照着色前后的原亮线是否出现暗槽。

这些反例检查的是同一块背景如何成像，不仅是开关有没有像素差。遇到失败先回到首次出现异常的那一层，区分违反既有规则、验收遗漏与规则留白；不要为此改掉已经通过的层。
