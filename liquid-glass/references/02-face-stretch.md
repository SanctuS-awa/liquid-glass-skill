# 2. 正面双端展开：不是「内收」或反向抵消

在第一层输出上工作。在正面靠边的一片区域，**同一片背景光既沿着边向本边的两端拉长，也沿局部法向往真实边缘靠。** 两个变化都属于第二层；不能只有沿边位移，也不能把法向靠边完全交给第一层。区别于第一层的单纯法向作用，也区别于第三层沿薄外沿拖长尾迹。不要扩大到中央。横边的两端在左右，竖边的两端在上下；写「两端」而不是把所有边都拉去全局左右角。

- 以真实直边为局部分段，中部向两端过渡。相邻直边的影响在圆角上连续接力；有两股方向不同时，在弧内逐步换向而不是在切点突然归零。圆角只有径向替代、直边效应只贴裁切遮罩，均不满足。内侧成像也应弯进弧里；不要让光出剪影。
- 胶囊直边各自朝两半圆端展开，在半圆的整段上做衔接，不把退化的零长直边当真。纯圆没有端点，可以从连续径向展开起步，但不得仅把 L1 统一加强或加宽来充作 L2。必须用同帧 L1 → L1+L2 证明：宽色带的近沿一段另有可辨的形态或间距变化，并更靠近轮廓，内侧仍接回未经 L2 的 L1。是否需要额外沿弧分量由实测决定；不要硬拆出端点、四分区或写死顺逆时针。
- 局部作用深度相对本处第一层较小，先以第一层有效深度的约三分之一至二分之一为比较量级，必要时再窄。此量仅指导调校，不等于面积、沿边距离或倍率，也不要求每处套同一比例。不能为消缝把第二层缩到看不见。
- 可用沿轮廓坐标的平滑位移或连续流；实现不限。朝中央必须接回第一层的位置与局部变化速率，真实轮廓边的交接也须检查，不只验证向量连续。能见尖点时，用同纹理分别开 L1、L1+L2，判断尖点是 L1 本就有、L2 取样造成，还是来自色块/扩散。不要用第三层或模糊遮住。


## 双方向验收、反向取样与圆角

- 以第一层成像为测量原点。上沿两个可辨光点分别在近沿的左右半边；打开第二层后，左点的沿边位置更靠左端、右点更靠右端，两点之间的距离增加。同理，竖边上半朝上端、下半朝下端。这是**像的移动**，不是对着线的倾斜方向运算。 同一对标记到真实轮廓的法向距离也须比只开 L1 时更小。只看到两点的沿边间距变大、离边距离却不变，不通过。选本来尚有离边距离的标记，不要求已在剪影边上的点越界，不把全片压成一条线。
- 若用输出坐标反查第一层：在上沿右半直边，要让一个源点出现在更右边，右边输出位置应往较靠本边中部的源位置找它，而不是再往右边找。左半镜像。对法向也一样：要让本来离边更远的像出现在更贴边的输出位置，就在第一层的像里往里找对应来源；不固定公式。只跟踪本层负责的近沿区域。沿边判向时，在直边中心之外只取更外端的源，通常恰好会把像往中部挤。不要只看 shader 向量箭头，用实际标记位置核对符号。
- 另挑一处纹理能跨直边与圆角切点的背景，分别截图 L1 和 L1+L2。切点两侧第二层的贡献应连续，不能在切点强制归零、让圆弧只剩径向效果。相邻直边确实要改变走向时，在弧上过渡。若观察到回钩或断点，分别记录它首次出现于 L1 还是 L2；不把 L1 的失效归给 L2。
