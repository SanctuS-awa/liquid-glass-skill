# 第四层模糊度标准：两道门槛，分别验第四层与最终材质

此标准测的是**输出保留多少背景细节**，不是指定 blur 半径。以下数字是本 Skill 的默认质检区间，不是 Apple 参数、物理常数或从官方截图反推的数值。用透明液态玻璃的默认外观验收；若产品另有不透明或高对比模式，单列，不能替代默认档。

## 冻结场景，给背景放两种尺寸的探针

1. 在实际尺寸、实际显示比例下测，同帧、同轮廓、同位置、同曝光。一处用均匀深底或带纹理底，另一处用真实产品画面。渲染 B0（无玻璃）、B3（三层折射）、B4a（只加普通模糊）、B4b（再加亮晕）、B5（常规高光）、B6（全开，诊断时可暂时隐去前景）。数值用未调色、未重新压缩的 PNG 或同精度原始帧。
2. 定义局部厚度 W 为被测点附近、沿最近外沿法线穿过玻璃的跨度，从一侧实际边到另一侧实际边；有孔时内孔是边。窄笔画不能用整词字号、字的包围盒或整条路径长度代替 W。大厅面板、胶囊、弯角和动态笔尖用各自局部尺度；不以 W 唯一决定滤波半径。
3. 在被测区域底图放**均匀、低对比的细中灰纹**（约 0.20–0.35 S 周期）与一处**明确可追踪的主边界或双结构**（间距约 0.45–0.85 S）。S 是测试采用的局部成像区域尺度，不大于 W：笔迹可用实际 W；大面板应按背景字行或图案的实际尺度选 S，而不是用整张面板的厚度把「细纹」变成巨型条纹。大面板在实景另复查一档不同的细节尺度。可用同场景分开两个测量窗，亮度均低于该实现高亮扩散主要响应区。不同尺寸同规则布点；细纹至少得到原生 3 个像素/周期，每处主边界两侧各能取稳定样本。如果实物太窄，不放大渲染冒充验收：找实际够宽的正常状态记录；其余位置标明「所用比例不可可靠量测」，仍检查透射不跳、不被染成实心。附有[可缩放测试底图生成器](../scripts/check_clarity.py)，不要把它的颜色或尺寸写进成品。
4. 测量尽量在高光肩以外、无前景覆盖的**同一真实材料内部**；用中线附近作为笔画的主结构检查；不要在强高光边故意量不出的区域代替整个材料。标注一次 B3 中的边缘、峰/谷和两侧同面积窗口，后续用同一坐标，禁止每层另挑最有利的点。若 B3 的位移把探针推到边外，重摆探针而不是推断其被模糊。B0 用来比位置，不用未折射的 B0 对比度冒充 B3 的基线。

## 两道通过线

取线性亮度 Y = 0.2126 R + 0.7152 G + 0.0722 B（先转线性 RGB）。局部对比 C 是固定两组采样窗口的平均 Y 差的绝对值。同一探针在 B3 初始对比必须足够辨认：细纹 C ≥ 0.035，主边界 C ≥ 0.060（Y 归一到 0–1）。太弱、噪声大、截断或高光混入时标无效，重新取帧，不填零，也不判通过。

| 判项 | 通过门槛 | 拒绝 |
| --- | --- | --- |
| B3 → B4a：普通软化的下限与上限 | 细纹对比比值 **0.40–0.85**；默认下肉眼确实更柔。主边界/间距对比至少保住 **0.75**，两条边原先能分开，开启后仍分开。 | >0.85（细纹过锐）；<0.40 或主结构变成均匀雾；用晕或高光补。 |
| B3 → B6：整件玻璃的透射底线 | 主结构对比至少保住 **0.60**。同一背景边从旁边未覆盖处进玻璃后，仍看得见它弯、偏、拉长的哪一种变化，出了玻璃能接回原边。 | B4a 数字过了但 B6 只见材质色/白边/雾面，看不见这条结构。 |
| 折射仍可见 | 用一条在 B3 里相对 B0 实际可分辨、位移至少 1 个原生像素且超过量具不确定度的主边。提供时才算位移量测：B6 位移与 B3 同向、绝对值至少保留一半；无法稳定位移时做有辨识度的实景连续轨迹验证，且不得报位移数值为通过。 | 折射一开始就不明显，或者靠模糊/均匀发亮把偏折藏起来。 |

比值不是最终视觉验收的替代。对正常比例的 B0/B3/B4a/B6，找一条明显的实景主结构，检查它到边、入内、出边都可追溯。背景小字可失去辨识度，不要求每条微纹都能读；但不许用「看得出背景底色」替代「看得出光的结构与折射」。大面板的字体、图标、常规背景色块；笔迹/窄控件的环孔、穿过笔画的同一条背景边，在各自场景分别验。整件材质换底、动画停稳时仍做一次复查。不同产品目标若有特定量测区间，先明示档位和参考证据，不得在做出效果后移动本门槛来凑通过。

## 失败时定位到首个把背景抹掉的阶段

- B3 已不成立：先修折射和测试场景，不能只调 L4。
- **B4a 首次失去细纹或主结构**：先减宽模糊的混合量或有效范围，保留一部分同帧已折射的清晰像。不要同时更改曝光、位移、亮晕。
- **B4a 过而 B4b 不过**：亮晕造成发白或断开的峰，调亮晕自身的范围、强度与衰减，不加/减普通模糊糊过去。
- **B4b 过而 B5/B6 不过**：查高光宽肩、白光或淡色覆盖、L6 混合量。常规高光不能把内圈整片刷成奶白/粉灰。即使叫「表面反光」或「提高可读性」，大面积替换底图仍不合格；不能削弱 L4 去抵消固定面色。
- 做四个控制档：B3 原样（检查过弱门槛）、候选默认、刻意过糊、候选正常 L4 加面内均匀染色。量具必须让过糊在 B4a 失败、让覆盖底图的染色在 B6 失败。两种反例不得都归咎于 L4。

[数值检查器](../scripts/check_clarity.py)读取经配准的线性亮度窗口数组，或直接指定 PNG 中不重叠的采样坐标。输出分项失败和自测；可用于复跑，但不能代替原尺寸图片和实景判断。
