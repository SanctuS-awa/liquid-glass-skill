# 背景来源与平台资格

把材质条件、可取得的背景和可用的渲染后端分开。Web 上区分应用自绘场景、允许暴露的背景与浏览器外部内容；Windows 和 Linux 区分自家窗口与窗后内容，后者受合成器、会话、权限及内容保护限制。取得某个平台的背景能力不代表其它平台也有，不假定任意来源可读。

每帧校验授权和来源，核对采集时刻、映射、视图尺寸、比例、显示密度、裁剪、安全的采样余量及颜色映射。不要从玻璃自身循环取样，也不要把越界、无权限或坏帧当作黑色背景。按背景变化速度和错位代价定新鲜度预算；正常更新迟到时，上一帧相容、仍获授权且未过时就继续用，不无故闪回磨砂。几何改变后，只有经核对覆盖和映射都仍适合才沿用旧帧，不能硬套旧尺寸或无限冻结。新帧重新合格才恢复。

来源不可用或后端做不到时，可显式降级成普通磨砂或产品指定外观。区分暂缓换帧与不能成像，记录降级原因、恢复条件，验证迟到、过期、尺寸比例变化和恢复的行为。平台的磨砂演示不能算材质验收。

如果取样和界面更新异步，给背景快照、轮廓/屏幕映射和合成结果登记同一组可对应的版本号。显示轮廓、前景与光学层前，以渲染后端实际确认的同帧组配提交；不能把新 UI 形状贴在旧光学位置。不能原子换帧时，明确相容范围，超范围按上面的回退规则。需要区别拖影和固定折射时，做[同速度正反扫光](field-trials.md)。

## 尺度变化与动画

在每帧按当前轮廓与背景坐标同步更新，而不是把小胶囊的折射图放大后当作大展开。固定背景，取起点、至少三个中间节点与终点；记录轮廓、取样位置、L4 普通模糊与亮部扩散是否跟随当前尺寸，详见[验收协议](acceptance.md)。静态起点/终点先单独验收；动画过渡不能掩盖站定后仍出现的尖点、断裂或尺寸错配。不规定某套动画时间曲线、交互 UI 或文字符号参与折射的方式。

动画中的文字色散不列作验收、开关或备选方案。若项目另外提出这种效果，先比较基线与其增量成本。固定背景和可预计算素材与实时、额外采集的成本不同；实测目标设备的帧耗时、峰值和采集开销，依项目预算决定适用性，不套全平台 GPU 百分比上限，也不为了保附加动画牺牲静态核心材质。
