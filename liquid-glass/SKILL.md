# Liquid Glass：六层成像语言（V7.21）

先确定哪一片背景光从哪里到哪里，再用图案识别成像变化。图案是探针，不是算法输入的语义；不得按识别出的线条方向、颜色面积或者图块边界来驱动几何。这里定义可观察结果，不声称复刻苹果内部实现。圆、胶囊、圆角方框是同一语言的不同形状，不是三个互不相关的特效。

| 层 | 读取什么 | 要看见什么 |
| --- | --- | --- |
| [1. 法向拉伸](references/01-normal-stretch.md) | 原始背景 | 近沿一片像沿对应轮廓的正交方向连续拉伸。直边不把光拉往角；圆角沿自身法线，内侧自然回到原背景。 |
| [2. 正面双端展开](references/02-face-stretch.md) | 第一层的像 | 在更窄的正面近沿，同一片像既向本边两端展开，又沿局部法向靠近轮廓。两种变化都要看得见；直弧接得上，圆形不虚构端点。 |
| [3. 外沿细带延展](references/03-rim-stretch.md) | 前两层的像 | 以触点所在半侧判初始方向，左向左、右向右；沿真实轮廓把局部成像带远，起始方向分区两侧同规，分界线垂直于当地轮廓切线；已经成像的尾巴可跨中线，且实际变细。两条尾巴相遇仍各自可追溯，不大面积串色、不硬切。默认细尾应明显超出直接接触段，仍能追溯其来源；带宽和沿边行程独立，不越过玻璃剪影。 |
| [4. 模糊与亮部扩散](references/04-diffusion.md) | 三层完成后的折射像 | 普通模糊在正常大小、关亮晕时也须一眼可辨，中央、直边和圆角内的纹理都要柔化。采用[模糊度双门槛](references/04-clarity-gate.md)：B4a 细纹对比保留 40–85%，主结构至少 75%；全开仍至少 60% 且偏折可追踪；亮光从折射后的实际成像位置展开，默认就有清楚可辨、逐渐淡去的长光晕；换底或展开时应平滑改变可见柔化与扩散，不能只换底色，近黑不自产亮晕；不搬走、不复制折射细尾，三段折射仍可追踪。 |
| [5. 常规高光](references/05-highlight.md) | 表面形状、光向与邻近背景光色 | 左上、右下有局部亮核与朝内柔肩，右上、左下收窄成弱丝光。沿直边和圆角顺滑过渡，亮度、真实带宽和向内衰减都要变，不能做成等宽白线。常规高光本身就将邻近的背景光色与白光混合，不需要折射接触；L6 只负责实际抵达的色光再沿高光延开。 |
| [6. 接触延色](references/06-contact-color.md) | 扩散前折射像、同帧原背景和第五层覆盖 | 被折射带来的光碰到高光才触发。从直接接触段的两个端点分别向外，沿同一条高光都能看见来自该段的颜色连续渐淡，两侧可不等长。用抵达光的色相，不照搬其曝光；不能把原高光压暗成看似断线。不染玻璃面，不染独立背景，不扩大高光覆盖，不改已合成的玻璃底图。 |

**规范与验收分开。** 实现要遵守本表和各层参考的输入、输出与禁止项；实现自由不等于验收可省略。看[验收协议](references/acceptance.md)决定测试顺序、通过条件和交付证据；要做跨模型复现时，用 [固定盲测素材](assets/fixtures/README.md)。

**执行顺序。** 背景 → 1 → 2 → 3 → 4 → 5/6 的高光合成 → 前景文字与图标。「5/6」不表示两次叠亮：第五层先定义本来的高光位置、光强和法向带宽，第六层在其合成前修饰颜色；第六层是单独的行为/开关，不要求独立的物理通道。第五层关时第六层无贡献，第六层旁路时得到原五层；第六层读第三层输出而不是第四层光晕。文字和图标默认不折射，不算材质的第七层。无独立强制阴影；未定义的额外底部光映射不得自行加入。不要把无关背景内容铺进面板，不做整圈背景色描边。

**同一界面只用一套玻璃材质。** 同一页面或应用界面的玻璃组件，共用圆角规则、基础模糊、底色与透度、边光和降级策略。不同轮廓可以随尺寸变化，背景可以自然透出明暗与颜色，但不允许组件自己换成黑底、白磨砂或近乎全透明。主题切换要同步。详见[同界面材质一致性](references/material-consistency.md)。

**先定职责再选方法。** 实现某一层前只读该层参考，做完整材质时依次读六层。设计中明确区分源区域、输出覆盖、法向带宽、沿边行程、位移与局部倍率。连续位置仍可出现倍率突变造成的尖点；一帧截图的形似不证明取样正确。默认 L1 的局部采样顺序不折回；能看见相邻标记的法向间距变大而不是重复取样。正圆须证明 L2 另有可见、限于近沿的贡献。实现交付前必须用[逐层反例](references/verification.md)验收；未做或未通过的要单列，不能以合成截图冒充。稳定版优先保住静态成像；不通过动画、美化背景或减弱某层掩盖问题。

**调校与交付。** 采用形状和局部曲率推导初值，作用区、拉伸强度/行程、模糊度与延色分别有默认值并知道怎么调；无需用户可见的调整 UI。像素可以是渲染单位，不是跨形状的材质规范。实现组合与验收看[校准与验收](references/verification.md)；接入真实背景、跨平台或动画时看[平台与帧](references/integration.md)。基准网页只证明已观察到的效果，不把它的固定数值、折回或小折痕作为规范。
